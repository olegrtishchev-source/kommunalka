## Известные проблемы
- **Экран входа показывает сырой текст исключения** (найдено 07.10.2026): `login_screen.dart:45` выводит `'Не удалось войти: $e'` — пользователю виден весь стек (`AuthRetryableFetchException ... SocketException ... errno = 7`) и URL Supabase. Нужен перевод частых ошибок в понятные сообщения (нет сети / неверный пароль / неверный email). Кандидат на 7.1 «Обработка пограничных случаев».
- «new blank line at EOF» в `ТЗ.md`/`План_выполнения.md` (от автоформаттера Markdown) — безвредно.
- Release-сборка `assembleRelease` (R8) идёт долго (первый прогон ~13 мин) — это нормально, последующие быстрее.
- Предупреждение сборки: плагин `flutter_web_auth_2` применяет Kotlin Gradle Plugin (KGP) — будущие версии Flutter могут потребовать обновления плагина. На текущую сборку не влияет.
