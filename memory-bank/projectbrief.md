# Project Brief — Kommunalka

## Что это
Мобильное приложение (Flutter, только Android) для **личного учёта показаний счётчиков и оплаты ЖКУ**. Заменяет ручной учёт в Excel и разрозненные квитанции единым инструментом.

## Кто и зачем
Один пользователь, личное некоммерческое использование, одно устройство (смартфон Android). Многопользовательский режим, роли, публичный доступ — не предусмотрены.

## Ключевые возможности
- Карточки поставщиков ЖКУ (с показаниями / без) с реквизитами, тарифом, каналами (в т.ч. производными).
- Ввод показаний → автоматический расчёт расхода и суммы.
- Экран оплаты: реквизиты, расчётная сумма, платёжный QR (ГОСТ Р 56042), передача показаний.
- Заполнение карточки сканированием QR квитанции.
- Чеки в Supabase Storage, история платежей со статусами.
- Синхронизация с Supabase, офлайн-просмотр через drift.
- Excel-отчёт по месяцу с выгрузкой на Яндекс.Диск.

## Стек (зафиксирован)
| Компонент | Решение |
|---|---|
| Клиент | Flutter (Dart), target Android |
| БД/синхронизация | Supabase (Postgres + Storage + Auth) |
| Локальный кеш | drift (SQLite) |
| Состояние | Riverpod |
| Навигация | go_router |
| Отчёты | пакет `excel` → Яндекс.Диск (REST API, OAuth) |

## Стадия
Активная разработка по этапам плана. **Этапы 0–5 (включая внеплановые 5.5–5.9) завершены**; идёт **Этап 6 «Сборка и тестирование»** (6.1 ✅, 6.2 — ручное тестирование в процессе). Далее — Этап 7 «Финальные штрихи».
