Пункт 0.7 — Подключение реального Android-устройства по USB (подробная инструкция)

Цель: чтобы flutter devices и adb devices видели подключённый телефон, и на нём можно было запускать Flutter-приложение.



Часть 1. На телефоне

Шаг 1. Включить режим разработчика.



Открой Настройки → О телефоне (у разных производителей: «О устройстве», «Об устройстве»).



Найди строку «Номер сборки» (Build number) — на MIUI (Xiaomi/Redmi/POCO) вместо неё нажимай «Версия MIUI».



Нажми на неё 7 раз подряд. Появится сообщение «Вы стали разработчиком» / «Режим разработчика включён».



Шаг 2. Включить отладку по USB.



Вернись в Настройки → Система → Для разработчиков.

Варианты пути в зависимости от производителя:



Samsung: Настройки → Параметры разработчика.



Xiaomi / Redmi / POCO: Настройки → Расширенные настройки → Для разработчиков.



Huawei / Honor: Настройки → Система и обновления → Для разработчиков.



Pixel / «чистый» Android: Настройки → Система → Для разработчиков.



Найди пункт «Отладка по USB» (USB debugging) и включи его.



Подтверди предупреждение «Разрешить отладку по USB?» — OK.



Шаг 3. Дополнительно (зависит от производителя).



Xiaomi: включи также «Установка через USB» (Install via USB) — на некоторых Redmi переключатель неактивен, пока не привязан Mi-аккаунт и/или не вставлена SIM-карта с номером; может появиться с задержкой после первого включения режима разработчика.



Huawei: может потребоваться «Разрешить отладку по USB» + «Проверять приложения через USB».



Samsung: кроме отладки может понадобиться установить драйверы Samsung USB Driver с официального сайта.



Шаг 4. Подключить телефон к компьютеру.



Подключи телефон кабелем USB к ПК. Кабель должен быть не «только для зарядки» — иначе данные не пойдут.



На телефоне появится системное окно «Разрешить отладку по USB?». Поставь галочку «Всегда разрешать с этого компьютера» и нажми «Разрешить».



Опусти шторку уведомлений на телефоне → выбери режим USB «Передача файлов» (File Transfer / MTP), не «Только зарядка».



Часть 2. На компьютере (Windows)

Шаг 5. Проверить, что Flutter видит устройство.



Открой PowerShell и выполни:



powershell

flutter devices

Ожидаемый результат: в списке появится Android-устройство (строка с именем телефона и android-arm64).



Шаг 6. Если flutter devices не видит телефон — проверить через adb:



powershell

\& "C:\\Users\\olegr\\AppData\\Local\\Android\\sdk\\platform-tools\\adb.exe" devices

Возможные статусы устройства:



device — всё хорошо, устройство подключено и авторизовано.



unauthorized — на телефоне не подтверждён запрос на отладку. Разблокируй телефон, найди окно «Разрешить отладку по USB?» и нажми «Разрешить». Если окно пропало — отключи и снова подключи кабель.



offline — устройство есть, но не отвечает. Помогает: adb kill-server → adb start-server → переподключить кабель.



пусто — устройство не определяется вообще (см. шаг 7).



Шаг 7. Если adb devices пуст — разбор причин.



Причина	Что делать

На телефоне не включена отладка по USB	Вернуться к шагу 2

Режим USB стоит «Только зарядка»	Переключить в «Передача файлов» (MTP)

Кабель «только для зарядки»	Заменить кабель на качественный data-кабель

Не установлен USB-драйвер производителя	Установить драйвер: Samsung — Samsung USB Driver; Xiaomi — Mi USB Driver; Huawei — HiSuite; Pixel — Google USB Driver (через SDK Manager)

Порт USB неисправен / разъём 3.0	Попробовать другой порт (лучше напрямую в материнскую плату, не через хаб)

Windows не видит устройство вообще	Проверить в Диспетчере устройств: должно появиться «Android Device» или «ADB Interface»; если там «Неизвестное устройство» — нужен драйвер

Если папка проекта «зависает» (Rename-Item/сборка сообщают «занято другим процессом») — открой Диспетчер ресурсов (resmon) → вкладка ЦП → Связанные дескрипторы → поиск по имени папки, обычно виновник adb.exe или зависший flutter run — завершить процесс и повторить.

Как будем работать по этому плану

Каждый пункт — отдельный шаг: реализация → проверка результата → переход к следующему, без забегания вперёд.



Репозиторий проекта — на GitHub.



Заведён justfile с рецептами запуска/сборки/проверки: flutter run -d <android-device-id>, flutter build apk --release, flutter analyze, dart format.



Файлы проекта Claude читает и пишет напрямую через мост.



Запуск и сборка (flutter run, flutter build) выполняются в PowerShell Олега — компьютер используется как среда сборки, приложение целится только на Android.



Периодически (после каждого этапа) — контрольная точка: таблица «Пункт плана — статус» и что осталось.
